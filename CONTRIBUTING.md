# How to Contribute

## 🧪 Submit Data
1. Record a tap using our firmware.
2. Fill out metadata (material, temp, etc.).
3. Submit a PR to `/data/material_glass_2mm_23C.json`

## 🛠️ Improve Code
- Fix bugs
- Add signal processing features
- Optimize for low-power devices

## 🤖 Train Models
- Use data to train better classifiers
- Submit `.tflite` models to `/models/`

## 🧰 Share Hardware
- Design 3D-printable mounts
- Build low-cost sensor nodes
